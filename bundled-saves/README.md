# Astrolux Motors Auto Dealer saved world

Astrolux Motors Auto Dealer

This ZIP and the installed Load-menu copy come from the same current working
release save, loaded and saved with the accompanying Build 42.21.0 candidate.
Use the two matching mods: PZ_TSB_AstroluxStructure and PZ_TSB_AstroluxTestMap.
Runtime fixes require those mods; the save ZIP alone does not install them.

Exit Project Zomboid before importing. Extract the ZIP into your game profile
(normally the Zomboid folder; a custom -cachedir uses its own profile).
The exact final path must be:
Saves/Astrolux Motors Auto Dealer/Astrolux Motors Auto Dealer/<save files>
Keep both named directory levels. Do not place this world under Sandbox,
merge it with another world, or overwrite an existing save.

Enable both matching mods and select Astrolux Motors Auto Dealer in Load.
To create a separate new world, select the Astrolux Motors Auto Dealer
Challenge. Use Load to resume the bundled world.
