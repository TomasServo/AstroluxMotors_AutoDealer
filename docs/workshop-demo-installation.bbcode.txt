[h2]TRY THE APPROVED SHOWROOM — SINGLE-PLAYER DEMO[/h2]
Explore the approved furnished Astrolux showroom on its 80×80 demonstration lot. Choose either the automatic demo or the optional saved-world download.

[b]Automatic demo — no ZIP extraction or separate program[/b]
[list]
[*]Subscribe to Astrolux Motors Auto Dealer and let Steam finish downloading it.
[*]Open Project Zomboid’s Mods menu and enable [b]Astrolux Motors Auto Dealer[/b] and [b]Astrolux Test Lot (Single Player Preview)[/b]. The test-lot mod is required for this demo.
[*]Return to the main menu and allow the game to reload its Lua files. Restart the game if prompted.
[*]Choose [b]New Game → Challenges → Astrolux Motors Auto Dealer Demo[/b], then create your character.
[*]The approved showroom is placed automatically once the area loads. No debug mode, manual tower paste or external installer is required.
[*]After quitting normally, use [b]Load[/b] to continue that world. Starting the challenge again creates a separate new world.
[/list]
Automatic sliding doors and mannequin outfit locks start enabled. Reloading preserves the existing world; it does not rebuild a tower you removed or reset your changes.

[b]Optional: install the frozen single-player save[/b]
The accompanying [b]Astrolux Motors Auto Dealer.zip[/b] is the preserved approved save. Exit the game, extract the ZIP to a temporary folder, and copy [b]Saves/Sandbox/Astrolux Motors Auto Dealer[/b] into your own [b]Zomboid/Saves/Sandbox[/b] folder. On a standard Windows installation this is [b]C:\Users\YOUR-NAME\Zomboid\Saves\Sandbox[/b]. Use your configured profile folder if you launch with a custom cachedir.

Keep the folder structure intact. Do not overwrite an existing save with the same name; keep a backup or give the imported folder a different name. Enable the two matching Astrolux mods, then select [b]Load → Astrolux Motors Auto Dealer[/b]. Workshop users should use the Workshop-provided mods rather than installing a duplicate local copy from the archive.

[b]If the demo is missing:[/b] confirm both mods are enabled, downloads are complete and the installed game meets the mod’s version requirement. This candidate targets Build 42.21.0 or later within the supported Build 42 release line; later updates still require compatibility verification. This is a single-player demo, not an automatic multiplayer server installer.
